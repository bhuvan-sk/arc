Connections & data flow

edge = f(source colour, transport)

A connector always takes the colour of the node it leaves, so a path reads as one swimlane end to end. The line pattern carries the transport, the arrowhead carries direction, and numbered markers carry sequence. Nothing else is allowed to encode meaning.
